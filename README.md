# ভূমি সেবা কেন্দ্র — GitHub Pages Website

বাংলা ভাষায় তৈরি একটি responsive ভূমি/অনলাইন সেবা ওয়েবসাইট।

## ফাইল
- `index.html` — মূল ওয়েবসাইট
- `style.css` — ডিজাইন
- `script.js` — মোবাইল মেনু ও বছর
- `assets/favicon.svg` — favicon

## GitHub Pages-এ প্রকাশ
1. GitHub-এ নতুন repository তৈরি করুন।
2. এই ZIP-এর সব ফাইল repository-তে upload করুন।
3. `Settings` → `Pages` এ যান।
4. `Deploy from a branch` নির্বাচন করুন।
5. Branch হিসেবে `main` এবং folder হিসেবে `/ (root)` নির্বাচন করে Save দিন।
6. কিছুক্ষণ পর GitHub আপনার ওয়েবসাইটের URL দেখাবে।
